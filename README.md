# TP5PEMWEB
1. Pengertian Bootstrap [10 poin] Jelaskan apa itu Bootstrap dan apa kegunaannya!
Jawab : Bootstrap adalah framework CSS open-source yang digunakan untuk memudahkan pembuatan website yang responsif dan memiliki tampilan konsisten. Bootstrap menyediakan komponen siap pakai, seperti navbar, tombol, form, card, dan sistem grid. Dengan Bootstrap, pengembang bisa membuat tampilan website lebih cepat tanpa perlu menulis seluruh kode CSS dari awal.
2. Memasang Bootstrap [10 poin] Ada beberapa cara untuk mengimpor atau menggunakan Bootstrap pada project. Sebutkan cara-caranya!
   Jawab :
  - Menggunakan CDN (Content Delivery Network): Menghubungkan file CSS dan JavaScript Bootstrap melalui URL CDN tanpa perlu mengunduh file secara manual.
  - Mengunduh file Bootstrap: Mengunduh file CSS dan JavaScript Bootstrap, kemudian menyimpannya di dalam folder project.
  - Menggunakan package manager: Memasang Bootstrap melalui package manager seperti npm untuk project berbasis Node.js.
  - Menggunakan source code Sass: Mengimpor dan menyesuaikan kode sumber Bootstrap menggunakan Sass agar warna, ukuran, dan komponen dapat dikustomisasi.
3. Grid dan Breakpoint [10 poin] Jelaskan mengenai class grid dan kegunaan breakpoint!
   Jawab : Grid adalah sistem tata letak pada Bootstrap yang membagi halaman menjadi 12 kolom sehingga elemen website dapat disusun secara fleksibel dan responsif.   Grid biasanya menggunakan class .container sebagai wadah, .row untuk membuat baris, dan .col untuk membagi kolom. Sementara itu, breakpoint adalah batas ukuran layar yang digunakan untuk menyesuaikan tata letak website berdasarkan perangkat yang digunakan. Bootstrap memiliki breakpoint sm (minimal 576 px), md (minimal 768 px), lg (minimal 992 px), xl (minimal 1200 px), dan xxl (minimal 1400 px). Contohnya, class col-12 col-md-6 membuat elemen memenuhi seluruh lebar layar pada perangkat kecil dan menggunakan setengah lebar layar pada perangkat berukuran sedang atau lebih besar. 
4.  Class Bootstrap [10 poin] Sebutkan minimal lima class yang disediakan oleh Bootstrap beserta kegunaannya!
   Jawab : Bootstrap menyediakan berbagai class yang dapat digunakan untuk mengatur tampilan dan tata letak website dengan lebih mudah. Contohnya, class .container digunakan untuk membuat wadah konten dengan lebar responsif, .row digunakan untuk membuat baris dalam sistem grid, dan .col digunakan untuk membagi tata letak menjadi kolom. Class .btn digunakan untuk memberikan tampilan dasar pada tombol, sedangkan .btn-primary digunakan untuk memberikan warna utama pada tombol. Selain itu, class .form-control digunakan untuk mengatur tampilan elemen input pada form, .text-center digunakan untuk membuat teks rata tengah, .mt-3 digunakan untuk memberikan margin atas, .img-fluid digunakan untuk membuat gambar responsif, dan .shadow digunakan untuk memberikan efek bayangan pada elemen.
5. Gambar Responsif [10 poin] Bagaimana cara agar foto atau gambar pada website responsif menyesuaikan ukuran layar perangkat?
   Jawab : Untuk membuat gambar responsif pada website menggunakan Bootstrap, kita dapat menambahkan class .img-fluid pada elemen <img>. Class ini menerapkan max width: 100% dan height: auto, sehingga ukuran gambar dapat menyesuaikan lebar wadahnya tanpa mengubah rasio aslinya. Dengan demikian, gambar dapat ditampilkan dengan baik pada berbagai perangkat, seperti komputer, tablet, dan smartphone, tanpa terpotong atau melebar secara tidak proporsional selama wadahnya diatur dengan benar.
